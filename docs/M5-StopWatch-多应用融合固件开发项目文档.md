# 一、项目概述

## 1.1 项目背景

M5Stack StopWatch 是一款搭载 ESP32‑S3R8 主控的圆形 AMOLED 触控开源开发板，出厂自带秒表、闹钟、电子徽章等基础功能。社区涌现了大量优秀的第三方开源项目，包括 VoiceCube 离线语音、小智联网 AI 助手、Stackchan 拟人互动等，但这些项目彼此独立、分散在不同仓库中，无法统一调度音频、WiFi、屏幕、IMU 等外设资源。

当前存在的核心问题包括：多模块音频外设抢占导致混音卡顿、第三方方形 UI 不适配圆形屏幕、各项目功耗策略不统一导致续航失控、功能切换需要重新烧录固件等。本项目旨在通过统一底层驱动、FreeRTOS 多线程隔离、前台单应用独占资源的调度机制，将多类功能整合进单一固件，依靠触屏与双侧按键在环形主菜单中自由切换。

## 1.2 项目目标

1. **统一外设底层驱动**：封装音频互斥锁、全局 WiFi 配置、电源休眠管控等公共 API，所有上层应用统一调用，杜绝外设抢占冲突。—— **✅ 音频互斥锁、WiFi 统一配网已落地；电源休眠管控待完善**

2. **搭建环形主菜单调度系统**：实现多应用切换、线程挂起/唤醒机制，前台仅一个应用激活运行，其余应用休眠释放资源。—— **✅ 主菜单已存在；调度机制以 mooncake 生命周期 + 单前台应用为准，深度休眠策略待完善**

3. **集成四大核心模块**：原厂工具箱、VoiceCube 离线语音、小智联网 AI、Stackchan 拟人互动。—— **🟡 原厂工具箱 ✅、VoiceCube（BLE 语音输入版）✅；小智联网 AI、Stackchan ⏳ 待接入**

4. **分批接入趣味拓展功能**：按 A/B/C 三级难度分批接入番茄钟、骰子模拟器、计步健康、消息看板等。—— **🟡 A 级完成 2/4（番茄钟、骰子）；抬手亮屏、弹幕时钟及 B/C 级待做**

5. **保障续航与稳定性**：日常续航对标原厂固件，长时间间歇运行稳定无死机、无内存泄漏。—— **⏳ 待压测**

6. **预留应用插槽**：支持后续新增第三方功能模块无缝接入菜单。—— **✅ app_template 已提供范式**

## 1.3 项目周期

总周期 **10 周**，分 4 个开发阶段（基于现状重排，见第五章）：

- **第 1–2 周**：基座补全 + 主菜单完善 + A 级功能收尾
- **第 3–5 周**：小智联网 AI 接入
- **第 6–8 周**：Stackchan 拟人互动 + B 级趣味功能

# 四、系统总体架构设计

- 按键中断 API：短按、长按、连击事件回调 ✅
- 音频 Codec API：录音、播放、音量、采样率配置 ✅

- WiFi 统一配网 API：STA/AP 切换、连接管理、配网引导 ✅
- 音频互斥锁 API：资源申请、释放、状态查询 ✅
